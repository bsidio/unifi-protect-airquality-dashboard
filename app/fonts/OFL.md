# Bundled fonts

Both faces are bundled as latin variable subsets so the container build needs no
network access and the browser makes no third-party request.

|---|---|---|---|

| `jetbrains-mono.woff2` | JetBrains Mono | [JetBrains](https://fonts.google.com/specimen/JetBrains+Mono) | SIL Open Font License 1.1 |
